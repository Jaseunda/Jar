# Changelog

All notable changes to **Jar** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to Semantic Versioning.

---

## [0.1.11] - 2026-10-02

### Added
- **Top Fade Gradient**: Added smooth fade overlay beneath the Store search bar so games gracefully scroll under the header.
- **Direct Installer Architecture**: Switched distribution package directly to `.pkg` with macOS native automated installation.

### Changed
- **Settings Typography**: Cleaned up subtitle and key shortcuts, replacing long dashes with clean separators.
- **Store Notes**: Formatted game disclaimer notices into dedicated cards matching the UI style.

---

## [0.1.0] - 2026-10-01

### Added
- **Native macOS Launcher**: Built modern SwiftUI launcher interface with dark theme and smooth spring physics.
- **Dedomil Catalogue Integration**: Browse and 1-click install classic Java ME games.
- **Device Profiles**: Preset phone models (Sony Ericsson K800i, Nokia N95, E71 landscape, and more).
- **Embedded J2ME Engine**: High-fidelity midlet player supporting LCDUI, M3G 3D, and audio.
